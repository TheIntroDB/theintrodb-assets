### TheIntroDB – Brand assets

---

Logos, badges and icons used by TheIntroDB projects and their READMEs. Files here are
hotlinked by name (raw.githubusercontent.com URLs do not follow a move), so treat the
paths as part of the interface.

| File | Use |
| --- | --- |
| `logo.svg`, `small-logo.svg` | Vector logo, full and compact |
| `logo-banner.png` | Banner lockup for README headers |
| `badge.png` | Square badge, used as the footer mark in every project README |
| `touch-icon.psd` | Source artwork for the touch icon |
| `logo-banner.psd`, `tidb-large.xcf`, `tidb-small.xcf` | Editable source artwork |

The squircle icons hotlinked by each integration README live in
[`TheIntroDB/.github`](https://github.com/TheIntroDB/.github/tree/main/integrations) instead.
